## 生产构建运行态检查

- 未授权行业周报计划任务返回 401；正确 Cron Bearer 返回 200。
- 一次计划任务写入 12 条，再次处理同一列表写入 0 条。
- 一页周报显示 12 条、12 个来源链接和选择进度。
- 选择条目返回 303，并在下一次客户档案第 0/6 章出现。
- 客户档案实际返回 0–10 章，真实年报档案有 108 个字段级来源链接。
- 服务启动日志不再出现旧的按公司轮询；旧模块保留但不自动导入。

## 唯一未到期的验收门槛

M6 要求真实连续四周由 FDE 每周选择至少 3 条有用信息。系统已经显示每周“已选择 / 至少 3 条”进度并保留写入状态，但四个自然周和人工“有用”判断不能由历史回放替代。上线后从首个周报周期开始记录，满四周后才能把该项标为通过。
